📖 操作指南

「工具应该是透明的。」

你打开它，记下几件小事，然后关掉它——就像在便签上划掉一行那样自然。没有账号，没有推送，没有永不停歇的红点。

好的工具，值得你慢慢发现。初遇时，你或许察觉不到它的好，只是寻常。但某一天，当你真正需要它——你会发现它始终在那里，安静、细腻、可靠。像一位沉默的爱人，不言不语，却从未离开。你拥有它时，不曾察觉什么特别；直到失去，才恍然明白——那正是你曾拥有过的，最好的温柔。

1. 基本操作

  • 添加事项：在输入框输入内容，按回车或点击「添加」
  • 完成事项：点击事项左侧的复选框，完成后自动沉到底部
  • 取消完成：再点一次复选框，事项回到顶部
  • 修改事项：双击事项文字进入编辑，按回车保存，按 Esc 取消
  • 删除事项：鼠标悬停事项，点击右侧删除按钮直接删除（无确认）

2. 设置提醒

直接输入时间（推荐）：在输入框里写上时间，系统自动识别：

  • 八点半下班、明天早上跑步、半小时后喝水
  • 每30分钟喝水 → 自动开启循环提醒
💡 下午说"八点半"会自动设为 20:30，晚上说则算明天早上

精确选择：点击输入框下方的「📅 选择提醒时间」，用滚轮选日期和时间。支持快捷选项：今天/明天/后天/下周一，以及「现在」按钮。

循环提醒：在时间选择器右侧开启「🔄 循环提醒」，可选每 30 分钟/1 小时/1 天/1 周，也可以自定义间隔。还能设置循环几次后自动停止。

到点会怎样：播放提示音 + 事项红框抖动 + 史迪奇弹出气泡提醒你。

提醒徽章：设置了提醒的事项会显示彩色徽章，颜色越深越紧迫：

  • 远期 灰色 — 超过 1 天
  • 接近 紫色 — 1 天内
  • 还有 N 分钟 橙色 — 1 小时内，带脉冲动画
  • 已过期 红色 — 已过提醒时间

3. 列表与收纳

  • 新事项在最上面：刚添加的事项显示在列表顶部
  • 已完成沉底：勾选完成后移到最下面的「已完成」区域
  • 收纳已完成：点击「还有 N 项已完成待办 ▼」可以展开或收起
  • 长文本自动折叠：超过 3 行会显示「展开」按钮
  • 每日日报：每晚 21:00 自动弹出，也能点击史迪奇随时查看

4. 史迪奇桌宠

  • 添加/完成/删除事项时，史迪奇会弹出气泡回应
  • 点击页面空白处，史迪奇会走到你点击的位置
  • 按住史迪奇可以拖动它
  • 点击史迪奇查看今日日报
  • 点击右上角 × 隐藏，左下角按钮可找回

5. 网页版

  • 打开方式：直接用浏览器打开即可使用，无需安装
  • 数据存储：所有事项保存在浏览器本地，刷新和重启都在
  • 提醒功能：需要保持页面打开（最小化或后台标签页都可以）
  • 添加桌面快捷方式：在手机浏览器中选择「添加到主屏幕」，打开后像 App 一样使用

6. 桌面端（Electron）

移动窗口：桌面端采用无边框设计，拖动标题区域即可移动窗口。

全局快捷键：

  • Alt+F：快速显示/隐藏主窗口（默认，可自定义）
  • Alt+G：切换便签模式（默认，可自定义）
💡 可在「设置 → 快捷键」中自定义为其他组合键

设置中心：右键托盘图标 → 「⚙️ 设置」进入，支持：

  • 开机自启动（开机后自动启动应用）
  • 快捷键自定义（修改全局快捷键，立即生效并持久化）
  • 检查更新（通过 GitHub 检查新版本）

便签模式：右键托盘图标勾选，窗口变成桌面便签（toolbar 类型，Windows+D 无法最小化）

  • 添加事项：标题栏「＋」按钮展开输入区，双击回车或按 Esc 收起
  • 折叠窗口：标题栏「▼」按钮，折叠后只显示标题栏
  • 窗口置顶：标题栏 📌 按钮
  • 滚动列表：待办项较多时，在列表区域滚动查看更多

7. 常见问题

Q1：事项太多怎么办？

已完成的事项会自动沉底，还能点击「还有 N 项已完成 ▼」收纳起来，让列表保持清爽。

Q2：史迪奇挡到内容了？

按住史迪奇可以拖动它到任意位置，也可以点击右上角 × 隐藏它。
