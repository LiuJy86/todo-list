1. 基本操作

  • 添加事项：在输入框输入内容，按回车或点击「添加」
  • 完成事项：点击事项左侧的复选框，完成后自动沉到底部
  • 取消完成：再点一次复选框，事项回到顶部
  • 修改事项：双击事项文字进入编辑，按回车保存，按 Esc 取消
  • 删除事项：鼠标悬停事项，点击右侧删除按钮直接删除（无确认）

2. 设置提醒

直接输入时间（推荐）：在输入框里写上时间，系统自动识别：

  • 八点半下班、明天早上跑步、半小时后喝水
  • 每30分钟喝水 → 自动开启循环提醒
  • 八点提醒我开会 九点提醒我吃饭 → 批量创建多个待办（v2.24.0）
💡 下午说"八点半"会自动设为 20:30，晚上说则算明天早上

精确选择：点击输入框下方的「📅 选择提醒时间」，用滚轮选日期和时间。支持快捷选项：今天/明天/后天/下周一，以及「现在」按钮。

循环提醒：在时间选择器右侧开启「🔄 循环提醒」，可选每 30 分钟/1 小时/1 天/1 周，也可以自定义间隔。还能设置循环几次后自动停止。

到点会怎样：播放提示音 + 事项红框抖动 + 屏幕右下角弹出桌宠独立提醒窗口。

独立提醒窗口操作：提醒触发时，屏幕右下角会弹出桌宠透明窗口，你可以：

  • 「知道了」：关闭窗口，待办保持未完成状态
  • 「稍后 5 分钟」：关闭窗口，5 分钟后再次弹出提醒
  • 「完成」：关闭窗口，同时将该待办标记为已完成
  • 点击桌宠：直接关闭窗口（等同于「知道了」）
  • 拖动窗口：按住桌宠图片可以拖动位置
💡 根据待办优先级不同，桌宠会显示不同表情：普通(可爱) / 中等(期待) / 紧急(着急)

提醒徽章：设置了提醒的事项会显示彩色徽章，颜色越深越紧迫：

  • 远期 灰色 — 超过 1 天
  • 接近 紫色 — 1 天内
  • 还有 N 分钟 橙色 — 1 小时内，带脉冲动画
  • 已过期 红色 — 已过提醒时间

3. 列表与收纳

  • 新事项在最上面：刚添加的事项显示在列表顶部
  • 已完成沉底：勾选完成后移到最下面的「已完成」区域
  • 收纳已完成：点击「还有 N 项已完成待办 ▼」可以展开或收起
  • 长文本自动折叠：超过 3 行会显示「展开」按钮
  • 每日日报（v2.22.0 优化）：每晚 21:00 自动弹出，也能点击史迪奇随时查看。采用 Apple 风格毛玻璃弹窗，大数字完成率显示，简洁直观

4. 桌宠互动

  • 添加/完成/删除事项时，桌宠会弹出气泡回应
  • 点击页面空白处，桌宠会走到你点击的位置
  • 按住桌宠可以拖动它
  • 双击桌宠：查看今日完成报告（完成率、已完成数量）
  • 点击右上角 × 隐藏，左下角「🐾 召唤我」按钮可找回
  • 桌面提醒：待办到点时，桌宠会从屏幕右下角弹出独立窗口，抖动提醒你
  • 自定义动图（v2.24.0）：可在「设置 → 个性化 → 桌宠动图」中添加自己的图片

5. 个性化设置（v2.24.0）

右键托盘图标 → 「⚙️ 设置」→ 「个性化」选项卡，可自定义提示音效和桌宠动图。

🎵 自定义提示音效：

  • 点击「选择」按钮，从本地选择音频文件
  • 支持格式：mp3、wav、ogg、flac、m4a、aac
  • 点击「▶」试听当前音效，再次点击停止
  • 点击「默认」恢复为系统内置音效

🖼️ 自定义桌宠动图：

  • 点击「添加」按钮，从本地选择一张或多张图片
  • 支持格式：gif、png、jpg、jpeg、webp、bmp、apng
  • 建议选择透明背景 GIF，与桌面融合效果更佳
  • 添加后会显示图片预览网格，点击「清空」可恢复默认
  • 自定义图片将同时用于：主页面桌宠 + 提醒窗口动图
💡 自定义资源存储在应用数据目录的 custom-assets 文件夹中

6. 网页版

  • 打开方式：直接用浏览器打开即可使用，无需安装
  • 数据存储：所有事项保存在浏览器本地，刷新和重启都在
  • 提醒功能：需要保持页面打开（最小化或后台标签页都可以）
  • 添加桌面快捷方式：在手机浏览器中选择「添加到主屏幕」，打开后像 App 一样使用

7. 桌面端（Electron）

移动窗口：桌面端采用无边框设计，拖动标题区域即可移动窗口。

全局快捷键：

  • Alt+F：快速显示/隐藏主窗口（默认，可自定义）
  • Alt+G：切换便签模式（默认，可自定义）
💡 可在「设置 → 快捷键」中自定义为其他组合键

设置中心：右键托盘图标 → 「⚙️ 设置」进入，支持：

  • 开机自启动（开机后自动启动应用）
  • 快捷键自定义（修改全局快捷键，立即生效并持久化）
  • 个性化设置（自定义提示音效、桌宠动图）
  • 用户引导（重新查看功能引导）
  • 检查更新（通过 GitHub 检查新版本）

便签模式：使用快捷键切换（默认 Alt+G），窗口变成桌面便签（toolbar 类型，Windows+D 无法最小化）

  • 添加事项：标题栏「＋」按钮展开输入区，双击回车或按 Esc 收起
  • 折叠窗口：标题栏「▼」按钮，折叠后只显示标题栏
  • 窗口置顶：标题栏 📌 按钮
  • 滚动列表：待办项较多时，在列表区域滚动查看更多
  • 注意：便签模式仅支持简单待办管理，需要完整功能时请退出便签模式

8. 常见问题

Q1：事项太多怎么办？

已完成的事项会自动沉底，还能点击「还有 N 项已完成 ▼」收纳起来，让列表保持清爽。

Q2：桌宠挡到内容了？

按住桌宠可以拖动它到任意位置，也可以点击右上角 × 隐藏它。

Q3：自定义音效/图片会丢失吗？

自定义资源存储在应用数据目录（%APPDATA%/ToDoList/custom-assets/），正常升级不会丢失。但卸载应用会清除这些数据（便携版除外）。

Q4：批量创建待办怎么用？

在输入框中输入多个待办，用空格分隔即可。例如：八点提醒我开会 九点提醒我吃饭 十一点提醒我洗碗，系统会自动识别时间并一次性创建多个待办。

Q5：提醒窗口没有声音？

检查系统音量是否开启，确认没有静音。如果是自定义音效，请确保音频文件没有损坏。可以在「设置 → 个性化 → 提示音效」中点击「▶」试听。
