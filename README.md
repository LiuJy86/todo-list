# ToDoList · 待办事项清单

> 好的工具，值得你慢慢发现。
>
> 初遇时只是寻常，直到真正需要时——才发现它始终在那里，安静、细腻、可靠。

一个简洁、实用的待办事项桌面应用，支持 Windows/MacOS 平台。

---

## 功能特色

- ✅ **简洁管理** — 添加、完成、编辑、删除，操作简单直观
- 🔔 **智能提醒** — 自然语言解析时间，支持循环提醒、批量创建
- 📅 **双时间提醒** — 支持开始时间 + 结束时间 + 结束前提醒
- 📌 **便签模式** — 桌面便签，始终置顶，Windows+D 无法最小化
- 📊 **每日日报** — 每晚 21:00 自动弹出完成率统计
- 🎨 **个性桌宠** — 趣味互动，支持自定义动图
- 🎵 **自定义音效** — 支持选择本地音频作为提醒音
- 🔄 **循环提醒** — 支持每 X 分钟/小时/天/周循环
- 📦 **批量创建** — 空格分隔一次性创建多个待办
- ⌨️ **全局快捷键** — Alt+F 显示/隐藏，Alt+G 切换便签模式
- ⚙️ **个性化设置** — 快捷键自定义、开机自启动、启动隐藏
- 🔍 **检查更新** — 通过 GitHub 检查新版本

## 使用示例

### 自然语言创建待办

直接在输入框输入：

```
八点半提醒我开会
明天早上跑步
每30分钟喝水
八点提醒我开会 九点提醒我吃饭 十一点提醒我洗碗
```

系统自动识别时间并设置提醒。

### 快捷键

| 快捷键 | 功能 |
|--------|------|
| `Alt+F` | 快速显示/隐藏主窗口 |
| `Alt+G` | 切换便签模式 |

可在设置中自定义。

## 开发与构建

```bash
# 安装依赖
npm install

# 开发模式运行
npm start

# 打包（安装版 + 便携版）
npm run build

# 仅打包便携版
npm run build:portable
```
