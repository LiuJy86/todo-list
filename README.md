一个简洁、实用的待办事项桌面应用，支持 Windows 平台。

## 功能特色

- ✅ 简洁的待办事项管理
- 🔔 智能提醒（自然语言解析、循环提醒、批量创建）
- 📌 便签模式（桌面便签，始终置顶）
- 📊 每日日报（完成率统计）
- 🎨 个性桌宠（趣味互动，支持自定义动图）
- 🎵 自定义音效（支持选择本地音频作为提醒音）
- ⚙️ 自定义设置（快捷键、开机自启动）

## 下载与安装

从 [Releases](https://github.com/LiuJy86/todo-list/releases) 页面下载最新版本：

- **安装版**（推荐）：`ToDoList-Setup-x.x.x.exe`
- **便携版**：`ToDoList-x.x.x-portable.exe`

## 开发与构建

```bash
# 安装依赖
npm install

# 开发模式运行
npm start

# 打包（安装版 + 便携版）
npm run build

# 仅打包便携版
npm run build:portable
```

## 技术栈

- [Electron](https://www.electronjs.org/) — 跨平台桌面应用框架
- 原生 JavaScript — 无额外前端框架依赖
- CSS 变量 — Apple 风格设计系统
