# 待办事项清单（Stitch 桌宠版）

> 工具应该是透明的。
>
> 你打开它，记下几件小事，然后关掉它——就像在便签上划掉一行那样自然。没有账号，没有推送，没有永不停歇的红点。只有你和你的待办，安安静静地待在一起。
>
> 我们相信，好的工具不会提醒你它有多强大，而是在你需要的时候恰好出现，不需要的时候悄然隐去。正如史迪奇说的：「Ohana，就是家人。」而家人，从不喧宾夺主。

## 理念

- **极简** —— 功能是做减法的艺术，留下的每一个按钮都经过犹豫
- **轻量** —— 不依赖框架，不依赖服务器，甚至不依赖安装。双击，打开，这就是全部
- **实用** —— 不追求「什么都能做」，只追求「这件事做得足够好」：记住该记的，提醒该提醒的，然后放手

## 功能

- ✅ 添加待办事项
- ✅ 标记完成 / 取消完成（勾选后自动沉底，保持未完成组向上冒泡）
- ✅ 删除单条事项
- ✅ 一键清除已完成事项
- ✅ 剩余事项计数
- ✅ 按 添加时间 / 内容 排序
- ✅ 本地存储（刷新页面不丢数据，`localStorage` 永久保留）
- ✅ 收纳机制：未完成项 ≥ 5 条时自动收纳；已完成项默认折叠收纳，点击"还有 N 项 ▼"可展开 / 收起
- ⏰ **提醒功能**（v2.1+）：
  - 自然语言解析提醒时间（支持「8:00 吃饭」「明天 8:00 跑步」「后天早上体检」「下周一交周报」「周五晚上聚会」「早上8点跑步」「今天晚上八点半下班」「明天下午三点开会」「八点半睡觉」「半小时后喝水」「过10分钟」「再过2小时」「一会儿提醒我」「每30分钟喝水」等表达，并自动清理「提醒我」「提醒」「叫我」等前缀）
  - **中文日期解析**（v2.7+）：支持「八月十五号提醒我开会」「十二月三十一日过年」「一月一号元旦」等中文月份/日期表达，自动转为数字日期
  - **自定义日期时间选择器**（v2.4+ / v2.5 滚轮优化）：替换原生 datetime-local，采用 Popover 浮层 + 滚轮选择器，两列布局（左列日期、右列循环/操作），支持日期/时间预设快捷选择、滚轮精调
  - **滚轮选择器**（v2.5+）：日期（月/日双列）和时间（时/分双列）均使用紧凑滚轮组件，拖拽/滚轮/点击三种交互，选中项精确居中，强遮罩只显示选中数字
  - **"现在"快捷按钮**（v2.5+）：时间预设行首按钮，一键设置为当前系统时间
  - 到点反馈：自定义提示音效（见下）+ 待办项红框抖动 6 秒 + 史迪奇弹气泡「该 XXX 啦！」
  - 三道触发保障（精确 setTimeout + 切回前台补触发 + 60s 兜底），避免浏览器后台降频漏提醒
  - 提醒徽章按紧迫度变色：远期（灰）→ 接近（紫）→ 紧迫（橙 + 脉冲 + 倒计时）→ 过期（红 + 删除线）
- 🔄 **循环提醒**（v2.4+）：
  - 支持循环开关，预设间隔：每 30 分钟 / 1 小时 / 1 天 / 1 周
  - 自定义循环：任意数值 + 单位（分钟/小时/天/周）
  - 完成自动开启下一轮：勾选完成 → 记录次数 → 自动推进周期
  - 悬浮查看：鼠标悬浮待办项显示提醒时间、循环设置、完成次数
  - 停止循环：点击 ⏹ 按钮可随时停止循环提醒
- 🔊 **音效测试按钮**（v2.2+）：提示条右侧的紫色胶囊按钮，任何时候点击都可立即验证提示音是否正常出声，并解锁浏览器音频授权（建议首次使用时点一下）
- 🔔 **提示音改用 MP3 文件**（v2.2+）：使用项目根目录的 `提示音效.mp3`，加载失败时自动回退 Web Audio 合成"叮咚"两声兜底，保证不会无声
- 📖 **内置操作指南**（v2.3+）：页面**右下角悬浮紫色圆形按钮 📖**（FAB 风格），点击即可在浏览器内打开 9 章节完整使用文档（含目录跳转、徽章示例、常见问题），无需查阅外部 README。与左下角的桌宠恢复按钮对称分居两角
- 🐙 **GitHub 仓库入口**（v2.3.2+）：右下角指南按钮上方的深色圆形 GitHub logo，点击在新标签页打开 [仓库地址](https://github.com/LiuJy86/todo-list)（需联网）
- 🧸 左侧史迪奇桌宠：GIF 轮播（3-5 秒随机切换 6 张动态表情）、点击空白召唤 + 自动避障（只在空白处走动，避开按钮/输入框/待办项）、拖拽时实时避让内容、气泡与内容重叠时自动隐藏、情绪联动（添加/完成/删除时切换开心/难过/生气等）、对话气泡 toast、可自由拖拽 / 隐藏 / 折叠、小窗口自适应显示（检测空白区域自动定位）
- 🖼 **应用图标**（v2.8.1）：使用史迪奇形象作为桌面应用图标（任务栏/快捷方式/安装包）
- ✏️ **双击编辑**（v2.8+）：双击待办事项文字可原地编辑，按 Enter 保存，按 Esc 取消
- 🔢 **目标计数**（v2.8+）：每条待办可设置目标执行次数（如喝水 8 次），点击「+」按钮计数，达到目标自动标记完成
- 💬 **史迪奇交互文字**（v2.8+）：新增中二/乐天/暖心风格的对话气泡，在页面打开、用户空闲、操作反馈、随机气泡四种场景触发
- 📊 **日报功能**（v2.8+）：每晚 21:00 自动提醒生成日报，也可手动点击史迪奇查看；日报显示今日完成事项、完成率、暖心结语
- 🗒 **便签模式**（桌面端）：右键托盘图标勾选「便签模式」，窗口变成桌面便签（toolbar 类型，Windows+D 无法最小化），只显示待办列表，不置顶不抢焦点，不影响其他软件；支持折叠/展开窗口（标题栏 ▼ 按钮）
- 📌 **窗口置顶按钮**（桌面端）：标题栏 📌 按钮可一键切换窗口置顶，置顶时按钮变红
- 📝 **长文本展开/收起**：待办事项超过 3 行自动折叠，显示「展开」按钮，点击可查看全文

## 运行方式

本项目支持 **浏览器** 和 **桌面端** 两种运行方式：

### 方式一：浏览器（无需安装）

直接双击 `src/index.html` 即可在浏览器中打开使用。

> **推荐**：使用本地服务器运行，避免 `file://` 协议下的 localStorage / MP3 预加载限制：
> ```bash
> # 进入项目目录后执行
> python -m http.server 8010
> # 然后访问 http://localhost:8010/src/
> ```

### 方式二：桌面端（Electron）

需要先安装依赖，然后启动：

```bash
# 安装依赖（首次运行前执行一次）
npm install

# 启动桌面应用
npm start
```

打包为可执行文件：
```bash
npm run build              # 打包为 NSIS 安装包 + 便携版
npm run build:portable     # 只打包便携版
```

> **⚠️ 提醒功能注意**：纯前端应用无后台进程，**浏览器完全关闭后 setTimeout / AudioContext 全部停止，无法触发提醒**。请将页面保持打开（最小化或放后台标签页都可以）。页面顶部橙色提示条会一直显示此提醒。
> **音效快速验证**：打开后先点一次「🔊 测试音效」按钮确认声音正常，顺便完成浏览器音频授权。

## 技术栈

- 原生 HTML / CSS / JavaScript（无框架、无后端、无数据库）
- 数据保存在浏览器 `localStorage`，关闭再打开依然存在（支持跨会话提醒调度）
- 音频：优先 `HTMLAudioElement` 播放 `提示音效.mp3`；兜底使用 **Web Audio API**（AudioContext + OscillatorNode + GainNode 音量包络合成"叮咚"声）
- 动画：纯 CSS @keyframes（收纳区 slideDown、提醒抖动、徽章脉冲、音效按钮 soundPulse、史迪奇情绪切换等）
- 响应式：Flexbox + `@media (max-width: 480px)` 窄屏适配（提示条按钮换行、输入控件自适应）
