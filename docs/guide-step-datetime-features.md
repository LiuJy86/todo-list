# 引导步骤新增：时间管理弹窗功能说明

> 设计文档 — 待审核后实施

## 1. 需求概述

在用户点击时间管理按钮（步骤4）之后，弹窗已经打开。需要新增一步说明弹窗的 4 个核心功能：

| 功能区域 | 说明 |
|----------|------|
| 📅 开始时间 | 设置任务开始日期和时间 |
| 🏁 结束时间 | 设置任务结束日期和时间 |
| ⏰ 结束前提醒 | 结束前 N 分钟提醒（5/10/15/30 分钟） |
| 🔄 循环提醒 | 周期性提醒（30分钟/1小时/1天/1周/自定义） |

## 2. 交互流程

```
步骤4: 用户点击时间管理按钮 → 弹窗打开 → 自动进入步骤5
步骤5: 高亮弹窗 + 说明功能 → 用户点击「下一步」→ 进入步骤6
```

## 3. 修改文件

| 文件 | 修改内容 |
|------|----------|
| `src/js/09-guide.js` | 在步骤4和快捷键步骤之间插入新步骤 |
| `tests/guide.spec.js` | 更新步骤编号，新增测试用例 |

## 4. 步骤配置

```javascript
{
  title: '提醒设置 ⏰',
  desc: '可以为事项设置提醒：\n\n📅 开始时间 — 任务何时开始\n🏁 结束时间 — 任务何时结束\n⏰ 结束前提醒 — 结束前 N 分钟提醒你\n🔄 循环提醒 — 周期性重复提醒\n\n设置好后点击「确定」保存',
  spotlight: '#datetimePopover',
  position: 'right',
  wait: null,
  action: { label: '下一步', fn: 'next' }
}
```

### 字段说明

| 字段 | 值 | 理由 |
|------|-----|------|
| `title` | `'提醒设置 ⏰'` | 点明功能 |
| `desc` | 四功能说明 | 简洁列出 |
| `spotlight` | `'#datetimePopover'` | 高亮整个弹窗 |
| `position` | `'right'` | 弹窗在左侧，卡片放右侧 |
| `wait` | `null` | 无需等待操作 |
| `action.label` | `'下一步'` | 继续下一步 |

## 6. 技术注意事项

### 6.1 弹窗状态

- 步骤4 点击后弹窗已经打开（`#datetimePopover` 可见）
- 步骤5 渲染时弹窗仍然存在，可以直接 spotlight
- 用户点击「下一步」时弹窗可以保持打开状态

### 6.2 边界情况

| 情况 | 处理 |
|------|------|
| 弹窗被用户关闭 | spotlight 目标不存在时自动隐藏高亮框，卡片居中显示 |
| 弹窗内容滚动 | 卡片定位在弹窗右侧，不依赖滚动位置 |

### 6.3 代码修改

只需在 TOURS 配置数组中插入新步骤，无需新增 wait 类型。
