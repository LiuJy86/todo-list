# 用户引导功能 - 最终执行文档

> 版本：v2.24.0 | 日期：2026-08-25 | 状态：已实现

---

## 功能概述

**手把手实操引导** —— 用户必须完成当前操作才能进入下一步，每步操作完成后高亮框移动到结果位置展示效果。

---

## 引导步骤（共 11 步）

| 步骤 | 操作 | 等待事件 | 完成后展示 |
|------|------|---------|-----------|
| 1 | 输入「九点半提醒我开线上会议」按 Enter | addTodo | 新添加的待办项 |
| 2 | 点击日历图标 | clickDatetime | 时间设置面板 |
| 2续 | 设置时间后点击确定 | confirmDatetime | 带时间的待办项 |
| 3 | 勾选待办标记完成 | checkTodo | 已完成状态的待办 |
| 4 | 点击收纳按钮展开 | clickCollapse | 收纳列表 |
| 5 | 按 Alt+F 两次（隐藏+显示） | altF | - |
| 6 | 按 Alt+G 进入便签模式 | enterSticky | 便签添加按钮 |
| 7 | 点击 + 按钮添加待办 | clickStickyAdd | 待办列表 |
| 8 | 点击折叠/固定按钮 | clickStickyCollapse | 待办列表 |
| 9 | 再次按 Alt+G 退出便签 | exitSticky | 输入框 |
| 10 | 双击史迪仔查看日报 | dblclickPet | 日报弹窗 |

## 技术实现

### 1. 脚本结构 (`08-onboarding.js`)

```
┌─────────────────────────────────────────────────────────────┐
│  1. 配置：STORAGE_KEY, CURRENT_VERSION, STEPS 定义          │
│  2. 状态：currentStep, overlay, highlight, card, cleanup    │
│  3. 核心函数：                                               │
│     - start()        → 检查版本，启动引导                    │
│     - createOverlay  → 创建遮罩层                            │
│     - renderStep     → 渲染当前步骤                          │
│     - positionStepHighlight → 定位高亮框（支持多元素）       │
│     - bindWait       → 绑定交互等待                          │
│     - showActionResult → 操作完成后展示结果效果              │
│     - next/skip/complete → 流程控制                          │
│     - reset          → 重置引导                              │
└─────────────────────────────────────────────────────────────┘
```

### 2. 交互等待机制

| wait 类型 | 检测方式 |
|-----------|---------|
| `addTodo` | `MutationObserver` 监听 `#todoList` 子元素变化 |
| `clickDatetime` | `click` 事件监听 `#datetimeTrigger` |
| `confirmDatetime` | `click` 事件监听 `#dpConfirmBtn` |
| `checkTodo` | `click` 事件监听 checkbox |
| `clickCollapse` | `click` 事件监听 `#collapseBtn` |
| `altF` | `keydown` 事件计数 2 次 |
| `enterSticky` | `MutationObserver` 监听 `body.class` |
| `clickStickyAdd` | `click` 事件监听 `#stickyAddToggleBtn` |
| `clickStickyCollapse` | `click` 事件监听 `#stickyCollapseBtn` |
| `exitSticky` | `MutationObserver` 监听 `body.class` |
| `dblclickPet` | `dblclick` 事件监听 `#stitchPet` |

### 3. 卡片定位算法

```
┌─────────────────────────────────────────────────────────────┐
│  1. 获取目标元素位置 (getBoundingClientRect)                 │
│  2. 计算高亮区域（元素 + 15px padding）                      │
│  3. 生成 10 个候选位置（下→上→右→左→四角→顶中→底中）        │
│  4. 依次检测：                                               │
│     - 是否在视口内                                           │
│     - 是否与高亮区域重叠                                     │
│  5. 应用第一个通过检测的位置                                 │
│  6. 都不通过则放在右上角                                     │
└─────────────────────────────────────────────────────────────┘
```

### 4. 多元素高亮

- 主高亮：实线框 + 脉冲动画
- 辅助高亮：虚线框（关联元素一起高亮）

### 5. 结果展示

操作完成后：
1. 状态更新为 ✅ 完成
2. 高亮框变绿
3. 400ms 后高亮框移动到 `showResult` 指定的元素
4. 滚动到可见区域
5. 1200ms 后自动进入下一步

## 重置引导

在 Console 执行：
```javascript
localStorage.removeItem('onboarding_done'); location.reload();
```

或在设置页点击「查看引导」按钮。
