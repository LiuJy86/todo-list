# 引导步骤新增：快捷键说明

> 执行计划文档 — 待审核后实施

## 1. 需求概述

在现有 5 步引导流程末尾新增第 6 步，向用户介绍两个核心快捷键：

| 快捷键 | 功能 | 说明文案 |
|--------|------|----------|
| `Alt+F` | 显示/隐藏主窗口 | 快速关闭和打开程序 |
| `Alt+G` | 切换便签模式 | 窗口变桌面便签，可穿透点击 |

## 2. 修改文件

仅修改一个文件：

- **`src/js/09-guide.js`** — 在 `TOURS[0].steps` 数组末尾追加一个 step 配置

## 3. 新增步骤配置

```javascript
{
  title: '快捷键技巧 ⌨️',
  desc: '两枚快捷键，效率翻倍：\n\n• Alt+F — 快速显示/隐藏程序窗口\n• Alt+G — 切换便签模式（窗口变桌面便签）\n\n快来试试吧！',
  spotlight: null,
  position: 'center',
  wait: null,
  action: { label: '完成引导', fn: 'complete' }
}
```

### 字段说明

| 字段 | 值 | 理由 |
|------|-----|------|
| `title` | `'快捷键技巧 ⌨️'` | 点明主题，emoji 增加辨识度 |
| `desc` | 两行快捷键说明 | 简洁列出功能，结尾引导尝试 |
| `spotlight` | `null` | 无特定高亮目标，居中展示 |
| `position` | `'center'` | 居中卡片，与 step1/step5 风格一致 |
| `wait` | `null` | 无需等待用户操作 |
| `action.label` | `'完成引导'` | 这是最后一步，点击即结束 |
| `action.fn` | `'complete'` | 调用 complete() 结束引导 |

## 4. 引导流程变更

### 变更前（5 步）

```
步骤1 → 步骤2 → 步骤3 → 步骤4 → 步骤5（完成）
```

### 变更后（6 步）

```
步骤1 → 步骤2 → 步骤3 → 步骤4 → 步骤5 → 步骤6 快捷键技巧（完成）
```

## 5. 影响范围

| 影响项 | 说明 |
|--------|------|
| 引导步骤数 | 5 → 6（进度点增加一个） |
| 徽章显示 | `步骤 6/6`（最后一步） |
| 跳过按钮 | 最后一步自动隐藏 skip 按钮（已有逻辑） |
| 其他文件 | 无影响 |
| CSS | 无新增样式 |
| 测试 | 如需更新引导测试，需同步调整 |

## 6. 实施步骤

1. 打开 `src/js/09-guide.js`
2. 定位到第 82 行（step5 配置结束）
3. 将 step5 的 `action` 从 `{ label: '完成引导', fn: 'complete' }` 改为 `{ label: '下一步', fn: 'next' }`
4. 在 `]`（steps 数组结束）前插入新步骤配置
5. 保存完成
