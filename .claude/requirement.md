# 待办事项清单需求



我想做一个网页：



1. 页面上可以输入一条待办事项​
2. 点击「添加」后，事项会显示在列表中​
3. 每条事项可以：​

- 标记为已完成

- 删除

4. 页面刷新后，数据存在 session​


5. 待办事项收纳（增强需求）：
- 未完成（待办中）事项超过 5 条时自动收纳，超出部分隐藏
- 已完成事项超过 3 条时自动收纳（沿用现有逻辑）
- 两类收纳共用一个「展开/收起」开关，点击任一收纳按钮都可切换
- 收纳按钮文案明确区分：「还有 N 项待办」（蓝绿色）和「还有 N 项已完成待办」（紫色）

6. 史迪奇桌宠交互增强（增强需求）：
- 史迪奇可以通过鼠标拖拽满屏移动，移动到任意固定位置
- 点击页面空白处可以让史迪奇走过去（召唤功能）
- 史迪奇移动时会自动避开功能按钮（添加按钮、输入框、待办项、收纳按钮等）
- 添加待办时史迪奇显示文字 toast 反馈（如「又多了一项待办，加油！」）
- 完成待办时显示庆祝 toast（如「干得漂亮！继续加油！」）
- 删除待办时根据状态显示对应 toast（warning/info）

7. 视觉与交互优化（v1.8.0 需求）：
- **桌宠动效**：将桌宠图片从 `史迪奇.png`（静态）改为 `史迪奇.gif`（动图），让史迪奇在网页上有动态效果
- **收拉框对比度优化**：原收纳按钮（collapse-btn）对比度太低、缺乏层次感，需增强对比度与层次感（加深背景色、加粗边框、增加阴影）
- **toast 改为史迪奇对话气泡**：用户说的「toast 表现」是指史迪奇的文字表现交互——取消页面顶部独立的 toast 提示条系统，所有待办操作反馈统一通过史迪奇自身的对话气泡（pet-bubble）展示，并根据操作类型（成功/信息/警告/错误）切换气泡颜色

8. 桌宠 GIF 多图轮播（v1.9.0 需求）：
- 将桌宠图片改为 `img/` 文件夹下的 GIF 动图（资源统一收纳到 img 文件夹）
- 每 3-5 秒随机轮播切换一张，共 7 张 gif 参与（史迪奇系列 6 张 + 线条小狗 1 张）
- 切换时淡入淡出，避免闪白突兀

9. 桌宠边界融入优化（v2.0.0 需求）：
- 桌宠融入不够自然，图片边界需要优化
- 修正图片路径：经核实 img 文件夹实际为 `史迪奇1.gif`~`史迪奇6.gif` 共 6 张（此前引用的 `史迪奇.gif`、`线条小狗.gif` 不存在导致 404）
- 优化图片边界融入：径向 mask 羽化边缘消除硬矩形边界、柔和双层投影让桌宠立体浮于页面、放大平滑弱化像素感

10. 待办事项提醒日期 + 音效（v2.1.0 需求）：
- **待办事项可设置提醒日期**：如「8:00 提醒我吃饭」「8月15日 提醒我开会议」也能提醒
- **到点通过音效告知用户**：使用 Web Audio API 程序合成「叮咚」提示音，无需音频文件
- **双重输入方式**：
  - 文本框自然语言解析（「8:00 吃饭」「明天8:00 跑步」「8月15日 8:00 开会」等）
  - 原生 datetime-local 日期时间选择器精确选时间
  - 两者结合互补
- **存储升级**：从 sessionStorage 升级到 localStorage，让提醒数据跨会话保留（否则关闭浏览器后提醒就丢失了）
- **三道触发保障**：精确 setTimeout + visibilitychange 漏检补触发 + 60s setInterval 兜底
- **提醒徽章按紧迫度变色**：远期灰、接近紫、紧迫橙脉冲、过期红删除线
- **到点反馈链路**：音效 + 红框抖动 + 史迪奇弹气泡「该 XXX 啦！」
- **已知限制**：浏览器完全关闭后无法提醒（纯前端限制），UI 上明确告知用户保持页面打开

11. 自然语言解析增强 — 中文日期支持（v2.7.0 需求）：
- **支持中文月份**：如「八月」「十二月」「一月」等中文月份表达
- **支持中文日期**：如「十五号」「三十一号」「一号」等中文日期表达
- **支持组合输入**：「八月十五号提醒我开会」→ 解析为 8月15日 9:00，事项「开会」
- **支持中文日期 + 数字时间**：「八月十五号 8:00 提醒我开会」→ 8月15日 8:00
- **中文数字增强**：支持「二十一」「三十一」等组合数字的解析
- **向后兼容**：原有数字格式（如「8月15日 8:00」）完全不受影响

12. 待办事项交互增强（v2.8.0 需求）：
- **双击编辑**：双击待办事项文字可原地编辑，按 Enter 保存，按 Esc 取消
- **目标计数**：每条待办可设置目标执行次数（如喝水 8 次），点击「+」按钮计数，达到目标自动标记完成
- **史迪奇交互文字**：新增中二/乐天/暖心风格的对话气泡，在页面打开、用户空闲、操作反馈、随机气泡四种场景触发
- **日报功能**：每晚 21:00 自动提醒生成日报，也可手动点击史迪奇查看；日报显示今日完成事项、完成率、暖心结语
- **自动收纳已完成项**：已完成事项默认折叠收纳，点击「还有 N 项已完成」展开查看
